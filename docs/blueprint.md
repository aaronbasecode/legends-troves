# **App Name**: Legends Troves

## Core Features:

- Interactive World Map: Display a zoomable and pannable interactive world map using Leaflet an open-source map API.
- Treasure Marker Placement: Populate the map with clickable icons representing the locations of undiscovered treasures sourced from a dataset.
- Treasure Information Cards: Display detailed information cards with the treasure's name, estimated location, and description upon clicking a treasure marker.

## Style Guidelines:

- Primary color: Deep gold (#D4AF37) to evoke a sense of treasure and discovery.
- Background color: Desaturated beige (#FFFFFF) for a vintage map aesthetic.
- Accent color: Earthy brown (#002F45) for interactive elements and highlights, analogous to gold but darker for contrast.
- Body and headline font: 'Rubik', a sans serif font.
- Use simple, custom icons for treasure markers.
- Ensure the map is the primary focus, with treasure cards appearing as overlays to avoid clutter.
- Subtle zoom and pan animations to enhance the map exploration experience.
